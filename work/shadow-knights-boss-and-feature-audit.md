# 그림자 기사단 v55 보스전과 기능 분석

해솔에는 **전진 중 자동으로 만나는 맵 보스**, **막힌 보스에게 다시 도전하는 버튼**, **전투 탭에서 골라 입장하는 챔피언 도전**이 각각 필요하다. 맵 보스는 길 위에서 만나고 이기면 그대로 앞으로 간다. 재도전은 수련 중 플레이어가 준비됐을 때 시간을 줄인다. 챔피언 도전은 본편에서 얻은 동료와 장비를 시험할 별도 전투다.

## 기사단에서 확인한 보스 진입과 결과

| 전투 | 진입과 진행 | 결과 |
| --- | --- | --- |
| 본편 스테이지 | 마지막 적이 사라지면 다음 웨이브를 자동으로 연다. 모든 웨이브를 이기면 출구로 이동해 다음 스테이지를 시작한다. 초반 스테이지에는 2웨이브부터 있고 뒤로 갈수록 최대 5웨이브가 등록돼 있다. | 일반 스테이지 패배 경로는 현재 월드의 첫 스테이지를 제외하면 스테이지 번호를 1 내리고 다시 시작한다. |
| 별도 보스 레이드 | 상단 `BossRaidButton`으로 목록을 열고 도전 가능한 카드의 버튼으로 입장한다. 승리 완료·현재 도전·잠금 상태가 카드에 표시된다. | 승리하면 해당 난이도의 진행을 저장하고 다음 카드를 열며, 클리어한 단계들의 능력치를 합산한다. 승리·실패 결과창이 각각 있다. 두 경로 모두 본편 스테이지를 다시 시작한다. |
| 군주 승급 | `KingClass` 전투에 따로 입장한다. 별도의 적·계수 테이블과 전투 시작 경로를 갖는다. | 성공하면 군주 등급을 올리고 성장 효과와 표시를 갱신한다. |
| 사냥 기록전 | 일일·경험치·그림자 장비 사냥을 별도로 연다. 모드별 최고 피해량 또는 도달 단계로 보상을 계산하는 경로가 있다. | 저장된 최고 기록을 소탕에 쓴다. 해솔의 30초 기록전과 대응된다. |

별도 레이드는 `level1` 씬의 `UI_TopRight/BossRaidButton`과 `UI_BossRaidSlot/Challenge`에서 확인했다. `OnClickChallengeButton`은 도전 상태를 검사한 뒤 `TryBossRaidStart`를 호출한다. `BossRaidStart`는 레이드의 적·웨이브별 공격력과 체력 계수를 불러온다. 승리는 `OnBossRaidEnd → OnBossRaidClear → Calculate → Save`, 실패는 `OnGameOver → UI_BossRaidResult.OpenFailed`로 이어진다. `BattleLocation`에서 본편·던전·사냥·승급·레이드는 별도의 값이다.

| 레이드 난이도 | APK 테이블 단계 수 | 한 단계의 웨이브 | 누적 보상 항목 |
| --- | ---: | ---: | --- |
| Normal | 30 | 3 | 공격력, 체력 |
| Hard | 30 | 4 | 치명타 확률, 치명타 피해 |
| Hell | 30 | 5 | 공격력, 체력 |

난이도별 행·웨이브 수는 `TBL_BOSS_RAID`에서 관계 데이터를 읽어 확인했다. 보상 종류는 `RewardStatType1/2`의 값을 `StatType`에 맞춰 확인했다. 클라이언트에 포함된 단계 수 기준이다. 서버에 따른 해금 상태, 전체 단계 플레이 가능 여부, 실제 보스 컷인과 제한시간은 이 분석의 검증 범위 밖이다.

## 해솔에 적용할 보스전 흐름

**현재**는 각 맵에서 18명을 이기면 40초 보스전이 자동으로 시작된다. 화면의 ‘보스 도전’은 상태 표시다. 실패 후 수련 HUD에 이미 **재도전** 버튼이 있고, 누르면 해당 맵의 첫 무리를 연다. 수련 3승을 기다려도 첫 무리부터 자동 재진입한다. 1-3 다온은 방어·반격·빈틈 패턴이 있고 스킬에 따라 공략이 다르다. 30초 기록전과 승급 심사는 별도 모드다. 현재 전투 엔진으로 자동 보스 진입, 시간 초과, 수련 3승 후 재진입, 기록전 입장권 차감을 실행해 확인했다. [전투 진행](recess/game.js#L894) · [보스 타이머](recess/ui.js#L378) · [현행 재도전 버튼](recess/ui.js#L1850) · [기록전](recess/game.js#L702) · [승급 심사](recess/game.js#L1246)

| 시점 | 플레이어가 볼 화면과 할 수 있는 행동 |
| --- | --- |
| 맵 보스에게 처음 도착 | 길 앞에 보스 등장, 이름과 짧은 패턴 예고, 제한시간 표시. 자동 전투로 들어가고 승리하면 출구 방향으로 계속 전진한다. |
| 보스에게 패배 또는 시간 초과 | 패배 시점의 남은 체력과 실패 원인을 보여 준다. 강화·편성을 바꾸는 동안 같은 맵에서 수련한다. 보스에게 도달한 맵에서는 수련 HUD의 버튼을 **보스 재도전**으로 표시한다. 누르면 이미 통과한 세 무리를 다시 잡는 구간을 생략하고 보스 앞까지 뛰어간다. 기존 자동 재시도는 수련 3승 후 같은 보스에 다시 연결한다. |
| 플레이어가 골라 도전 | 전투 탭에 **챔피언 도전** 카드를 둔다. 첫 버전은 1-3 다온을 이긴 뒤 해금하고, 수비형·난타형·잡기형 선수 3명부터 구성한다. 카드에 패턴 한 줄, 추천 동료와 이유, 첫 승리 보상, `도전` 버튼을 표시한다. |
| 별도 도전 종료 | 성공은 해당 카드 첫 승리와 다음 카드 해금을 기록한다. 첫 승리 보상은 동료 조각이나 명예 배지 중 기존 성장에 맞는 한 종류를 택한다. 실패는 남은 체력과 주요 패턴을 보여 주고, 결과 확인 후 본편에서 출발했던 위치로 돌아간다. |

첫 구현 범위는 **1-3 다온 패배 → 수련 → 보스 재도전**이다. 패배한 맵과 그 맵의 보스 도달 기록을 사용하고, 다른 지역·시즌의 진행을 건너뛰지 않게 한다. 본편과 챔피언 도전의 성공 기록을 따로 저장하고, 보상은 동일한 승리에 한 번 지급한다. 수동 재도전과 수련 3승의 자동 재시도가 겹치는 경우 다음 전투는 한 번만 시작한다. 중간에 닫았다 열거나 2배속을 켜도 같은 보스에 도착하는지 확인한다.
