# Codex 그림 요청 9차: 주인공 모션을 60프레임처럼 매끄럽게

작성 2026-11-18 · Claude · 받는 쪽 Codex

사용자 요청은 "움직임이 60프레임처럼, 진짜 격투하는 것처럼 매끄럽게"입니다. 주인공부터 먼저 하고, 괜찮으면 동료에도 넓힙니다.

## 지금까지 한 것 (코드 쪽, Claude)

- 7·8차 주인공 띠 17개는 원래 칸 사이마다 5칸을 광학 흐름으로 끼워 넣어 게임에서 재생합니다.
  - 칸 수가 약 6배가 됩니다(예: 펀치 6칸 → 31칸).
  - 도구는 `work/tools/smooth_strip.py`, 결과는 `assets/anim-boy-<동작>-smooth.webp`입니다.
- 동작이 바뀌는 순간에 0.07초 겹쳐 지우기, 상태마다 몸 이동의 가속·감속, 타격 잔상도 넣었습니다.

보간은 원래 칸 두 장 사이의 움직임이 작을 때만 깨끗합니다. 팔다리가 한 칸에 40px 넘게 움직이면, 중간 칸에서 팔다리가 늘어나거나 뭉개져 보입니다. 아래는 그런 곳과, 보간으로는 해결이 안 되는 곳입니다.

**원래 띠만 그려 주세요.** 매끄러운 띠(`-smooth`)는 받은 뒤 Claude가 도구로 다시 만듭니다. 규격은 7차와 같습니다(칸 280×255, 발 기준 가로 140·세로 249, 오른쪽 보기).

## 1. 칸 사이 움직임이 큰 곳에 중간 칸 1장씩 (가장 중요)

칸 사이 움직임의 크기를 쟀습니다. 숫자는 실루엣이 바뀐 넓이(%)와 많이 움직인 부분의 이동 거리(px, 95퍼센타일)입니다. 펀치(`anim-boy-punch`)는 칸 사이가 19~34px이고 보간이 깨끗합니다. **칸 사이 25px 안팎이 목표입니다.**

| 띠 | 큰 곳(칸 번호는 1부터) | 넣을 중간 칸 |
|---|---|---|
| `anim-boy-kick` | 2→3 (19.7%/52px), 4→5 (18.9%/45px) | 무릎을 들어 올리는 칸, 발을 거둬들이는 칸 |
| `anim-boy-knee` | 2→3 (14.8%/44px), 4→5 (17.4%/50px) | 무릎이 반쯤 올라온 칸, 내려오는 칸 |
| `anim-boy-combo` | 2→3 (16.2%/51px) | 두 번째 주먹이 반쯤 나간 칸 |
| `anim-boy-rush` | 1→2 (19.2%/42px), 2→3 (17.0%/47px), 5→6 (17.3%/48px) | 몸을 낮추며 앞으로 기우는 칸, 뻗는 중간 칸, 거둬들이는 칸 |
| `anim-boy-hold` | 1→2 (15.6%/44px), 3→4 (11.2%/44px) | 상대를 붙잡으며 몸을 낮추는 칸(8차 5번 요청과 같음) |
| `anim-boy-throw` | 3→4 (18.1%/37px), 4→5 (19.6%/38px) | 들어 올린 상대를 넘기는 중간 칸 |
| `anim-boy-counter` | 2→3 (18.7%/32px), 5→6 (17.7%/36px) | 반격 주먹이 반쯤 나간 칸 |
| `anim-boy-down` | 2→3 (11.0%/61px) | 무릎이 꺾이며 주저앉는 중간 칸 |

- **타격 칸 위치가 바뀝니다.** 타격 칸 앞에 칸을 넣으면 번호가 밀리니, 인수인계 문서에 띠마다 새 타격 칸 번호(1부터)를 적어 주세요. 지금 번호는 주먹·발차기·무릎·돌진·반격·연타 3번째, 메치기·굳히기 4번째입니다.
- 장비 마스크 띠(`animmask-boy-<동작>`)도 같은 칸 수·같은 자세로 맞춰야 합니다.

## 2. 맞음(`anim-boy-hit`): 3칸 → 5칸, 크게 젖히기

지금 3칸 사이 움직임이 5~6px뿐이라, 맞아도 몸이 거의 안 움직입니다. 지금 화면의 맞는 반동은 코드가 몸 전체를 뒤로 미는 것뿐입니다.

5칸 순서는 이렇습니다.
1. 충격: 고개가 뒤로 꺾이고 상체가 10~15° 뒤로 젖혀집니다.
2. 가장 크게 젖혀짐: 뒷발 쪽으로 무게가 실립니다.
3. 버팀: 앞발 무릎을 굽혀 버팁니다.
4. 가드를 다시 올립니다.
5. 대기 1번째 칸에 가까운 자세로 돌아옵니다.

## 3. 대기(`anim-boy-idle`): 숨 고르기를 더 크게

지금 6칸 사이가 1~2px라 거의 정지 그림처럼 보입니다. 서 있을 때 뻣뻣해 보이는 가장 큰 이유입니다.
- 격투 게임 대기처럼 무릎을 살짝 굽혔다 펴며, 몸 전체가 4~6px 오르내리게 해 주세요. 어깨와 주먹도 3~5px 함께 움직입니다.
- 6칸 그대로, 6번째 칸이 1번째 칸으로 자연스럽게 이어지게 해 주세요.

## 4. 장비 마스크: 상의·하의 경계를 옷 모양대로

지금 모든 주인공 마스크(`animmask-boy-*`)는 빨강(상의)과 초록(하의)이 허리 높이에서 가로로 반듯하게 나뉘어 있습니다. 그래서 허리 아래로 내려온 재킷 자락이 바지 색으로 칠해집니다. 메치기·굳히기처럼 몸을 숙인 칸에서 특히 잘 보입니다(재킷 위쪽만 새 색이고 아래쪽은 원래 색).
- 빨강은 재킷 전체(소매·자락 포함), 초록은 바지만 칠해 주세요.
- 파랑(태그)과 노랑(신발)은 지금 그대로 좋습니다.
- 17개 띠 모두 해당합니다. 마스크 칸 수는 그림 띠와 같아야 합니다.

## 5. (여유 있을 때) 새 동작 `anim-boy-getup`: 일어나기 4~5칸

지면 쓰러짐(`down`) 끝 칸에서 다시 도전할 때 바로 대기 자세로 바뀝니다. 쓰러짐 끝 칸 → 한 손 짚고 일어남 → 무릎 → 가드 자세로 이어지는 4~5칸을 그려 주세요(마스크 `animmask-boy-getup` 포함). 받으면 코드에 연결하겠습니다.

## 참고: 주인공 띠가 게임에서 쓰이는 방식 (원래 칸 기준)

| 동작 | 재생 |
|---|---|
| 대기 | 초당 7칸으로 반복(매끄러운 띠는 초당 42칸) |
| 달리기 | 초당 13칸으로 반복 |
| 승리·쓰러짐 | 초당 9칸으로 한 번 재생하고 끝 칸에서 멈춤 |
| 주먹·발차기·무릎·메치기·굳히기 | 공격 준비 동안 첫 칸~타격 앞 칸 → 타격 순간에 타격 칸 → 마무리 동안 나머지 칸 |
| 필살기·액티브 | 위 공격과 같은 방식 |
| 맞음 | 맞은 동안 첫 칸~끝 칸 |

- 칸 수는 바꿔도 됩니다. 게임이 띠 폭 ÷ 280으로 칸 수를 셉니다.
- 칸을 넣거나 빼면 인수인계에 타격 칸 번호만 알려 주세요.
