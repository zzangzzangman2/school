# Codex 그림 요청 7차: 대결 동작을 부드럽게 만들 중간 프레임

작성 2026-11-17 · Claude · 받는 쪽 Codex

화풍·질감·채색은 Codex가 정합니다. 이 문서에는 **프레임 수, 규격, 맞춰야 할 기준**만 적습니다. 코드 연결과 재생 속도는 Claude가 맡습니다.

## 왜 딱딱해 보이는가

지금은 동작 하나가 **정지 그림 한두 장**으로 되어 있습니다.

| 동작 | 지금 | 화면에서 보이는 것 |
|---|---|---|
| 주먹 공격 | windup → strike → follow 3장(0.28초) | 그림 3장이 순간이동하듯 바뀜 |
| 대기 | ready 1장(+ready-b) | 한 장을 위아래로 늘였다 줄임 |
| 달리기 | run 1장 | 한 장이 미끄러져 감 |
| 맞음·쓰러짐 | hit 1장, down 1장 | 한 번에 툭 바뀜 |

부드러워 보이는 방치형 게임은 동작마다 **6~10장**의 이어지는 그림(또는 뼈대 애니메이션)을 초당 12~24장으로 재생합니다. 중간 그림이 있어야 팔다리가 궤적을 그리며 움직입니다.

코드 쪽 원인(초당 24번 갱신, 위치 순간이동, 대기 그림 깜빡임)은 Claude가 따로 고칩니다. 이 문서는 그림이 꼭 있어야 하는 부분만 요청합니다.

## 공통 규격

- **한 동작 = 가로 띠 한 장**: `anim-{id}-{동작}.webp`, 프레임 하나는 지금처럼 280×255, 투명 배경, 오른쪽 보기입니다. 띠 폭은 280 × 프레임 수입니다(예: 6프레임이면 1680×255).
- **발 기준점 고정**: 땅을 딛는 프레임은 모든 동작·모든 프레임에서 발이 같은 자리(가로 140, 세로 249 근처)에 오게 합니다. 기준점이 흔들리면 재생할 때 캐릭터가 덜덜 떨립니다.
- **크기·비율 고정**: 프레임마다 인물 크기, 얼굴, 옷, 색이 같아야 합니다. 프레임끼리 얼굴이나 옷 무늬가 바뀌면 깜빡여 보입니다. 이어지는 그림을 고르게 못 그리겠으면 프레임 수를 줄여 주세요(6장 대신 4장).
- **동작 원칙**: 준비(뒤로 당김) → 타격(가장 멀리 뻗음) → 마무리(관성) → 복귀 순서입니다. 타격 프레임 하나는 잔상·번짐 표현을 넣어도 됩니다.
- **주인공 장비 마스크**: 주인공은 장비 외형을 합성하므로, 띠마다 같은 배치의 마스크 띠 `animmask-boy-{동작}.webp`가 필요합니다. 마스크 색은 5차와 같습니다(빨강 상의, 초록 하의, 파랑 태그·참, 노랑 신발).
- **확인용 미리보기**: 동작마다 반복 재생 GIF를 `outputs/recess-motion-preview-7/`에 같이 넣어 주세요. 발이 떨리지 않는지 그걸로 봅니다.
