# Codex 그림 작업 요청 3차 — 구글 플레이 정책: '싸움'을 '쉬는 시간 놀이 대결'로

작성 2026-11-17 · Claude · 받는 쪽 Codex

## 배경

구글 플레이 정책 때문에 초·중학교 구간이 학교 폭력처럼 보이면 안 됩니다. 그래서 게임을 **쉬는 시간 코믹 놀이 대결**로 바꿨습니다. 코드·문구·연출은 이미 끝났습니다.

- 문구: 싸움·구타·짱·일진·복종 같은 말은 모두 뺐습니다. 대신 대결·승부·쉬는 시간 제왕·골목대장·라이벌을 씁니다. 공격력은 '파워', 치명타는 '크리티컬'로 바꿨습니다.
- 학교와 종목: 회차마다 학교가 해솔초(6학년) → 해솔중(3학년, 학기 6개) → 해솔고 → 전국 리그로 바뀝니다. 학년마다 종목이 정해져 있고(`game.js`의 `CONTESTS`·`CONTEST_PLAN`), 화면 위 칩에 지금 종목이 보입니다.

| 학교 | 학년(맵 1~3 / 4~6 / …) 순서대로 종목 |
|---|---|
| 해솔초 | 딱지치기 → 지우개 따먹기 → 피구 → 코믹 밀치기 → 팔씨름 → 1:1 농구 |
| 해솔중 | 씨름 → 팔씨름 → 피구 대항전 → 농구 리그 → 태권도 겨루기 |
| 해솔고 | 태권도 겨루기 → 유도 대련 → 정식 스파링 → 농구 리그 |

- 던전 종목: 매점 줄서기 대회=딱지치기, 도서실 퀴즈왕=지우개 따먹기, 전국 체력장=1:1 농구, 승급 시험=팔씨름.
- 연출(지금은 CSS로 그린 임시 그림):
  - 맞는 곳에 주먹 스파크 대신 **먼지 구름**이 피어오릅니다. 태권도와 스파링만 반짝 스파크를 씁니다.
  - '딱!', '통!', '영차!' 같은 **의성어**가 뜹니다.
  - 공·딱지·지우개 같은 **종목 도구**가 상대 쪽으로 날아갑니다.

**문제는 그림입니다.** 지금 캐릭터 동작 그림이 전부 주먹을 내지르는 자세라서, 화면에서는 여전히 주먹다짐처럼 보입니다. 표지(`cover.webp`)도 두 아이가 주먹 쥐고 맞서는 그림입니다. 아래를 새로 그려 주세요.

공통 규칙은 [1차 요청서](codex-art-request.md)와 같습니다.

- 화풍: 치비 픽셀 아트, 투명 배경, 오른쪽 보기
- 크기: 서 있는 그림 255px 높이, 동작 프레임 280×255

그림을 연결한 뒤에는 `work`에서 검사 6종을 모두 통과해야 합니다.

```
py -I package_recess.py
py -I check_recess.py
py -I check_recess_combat.py
py -I check_recess_wardrobe.py
py -I check_recess_art.py
py -I check_recess_longterm.py
py -I check_recess_meta.py
```

## 그리는 원칙 (모든 그림에 적용)

- **주먹 금지.** 손은 펴거나, 공·딱지·지우개를 쥐거나, 상대 손을 맞잡는 모양으로 그려 주세요.
- 얼굴은 화난 얼굴 대신 **신난 얼굴, 집중한 얼굴, 장난스러운 얼굴**로 그려 주세요. 피, 멍, 눈물, 겁먹은 표정은 넣지 않습니다.
- **맞는 동작(hit)은 '깜짝 놀람'** 으로 그려 주세요. 눈이 동그래지고 몸이 뒤로 살짝 젖혀지며 머리 위에 땀방울이 하나 있는 정도입니다.
- **쓰러지는 동작(down)은 '털썩 주저앉기'** 로 그려 주세요. 엉덩방아를 찧고 머리 위로 별이 빙글빙글 돌며, 웃으면서 "졌다~" 하는 느낌입니다. 바닥에 눕거나 엎드린 자세는 쓰지 않습니다.
- 고등학교 정식 스파링·태권도는 **보호구**를 그려 주세요(헤드기어, 몸통 보호대, 글러브나 도복). 스포츠 경기처럼 보여야 합니다.

## 1. 주인공 종목별 동작 3묶음 (가장 중요)

종목마다 `motion` 값이 있습니다(`toss`·`push`·`spar`). 대결 화면 `#arena`에는 `data-motion`과 `data-contest`가 붙습니다. 그래서 CSS만 더하면 종목마다 다른 동작이 나옵니다.

| motion | 해당 종목 | 동작 느낌 |
|---|---|---|
| toss | 딱지치기·지우개 따먹기·피구·농구 | 딱지를 내리치거나, 지우개를 손가락으로 튕기거나, 공을 던지는 자세 |
| push | 코믹 밀치기·팔씨름·씨름·유도 | 두 손바닥으로 밀거나, 팔씨름 손을 맞잡거나, 샅바나 도복 깃을 잡고 버티는 자세 |
| spar | 태권도 겨루기·정식 스파링 | 보호구를 갖춘 정식 경기 자세(발차기, 글러브 잽) |

- 주인공 남녀(`boy`, `girl`)마다 묶음 하나에 **windup·strike·follow 3장**을 그려 주세요. 둘이면 총 18장입니다.
  - 파일 이름: `motion-boy-toss-windup.webp` 식
- 연결: `motion.css` 끝에 아래 형식으로 추가합니다. 기존 규칙보다 우선 적용되고, 그림이 없는 묶음은 지금 그림이 그대로 나옵니다.

```css
.arena[data-motion='toss'] [data-sprite='boy'][data-pose='windup'] { --pose-image: url('assets/motion-boy-toss-windup.webp'); }
.arena[data-motion='toss'] [data-sprite='boy'][data-pose='strike'] { --pose-image: url('assets/motion-boy-toss-strike.webp'); }
.arena[data-motion='toss'] [data-sprite='boy'][data-pose='follow'] { --pose-image: url('assets/motion-boy-toss-follow.webp'); }
```

- 남녀 공통 기본 동작 `ready`·`step`·`run`도 주먹을 쥐지 않게 다시 그려 주세요(손바닥을 펴고 신나게 뛰는 자세). 파일 이름은 기존과 같게 덮어쓰면 됩니다.
- `hit`·`down`·`victory`도 위 원칙(깜짝 놀람, 털썩+별, 브이 포즈)대로 다시 그려 주세요.

## 2. 상대 캐릭터 동작 다시 그리기

대상은 rival1~4, mob1~8, boss1~6, dboss-store·quiz·sports입니다.

- **필수:** 모든 상대의 `strike`(펀치)와 `hit`·`down`을 위 원칙대로 고쳐 주세요. 파일 이름은 같게 덮어씁니다.
  - strike: 손바닥으로 밀거나 공·딱지를 던지는 동작
  - hit: 깜짝 놀람
  - down: 털썩 주저앉기와 별
- **선택:** 주인공처럼 `toss`·`push`·`spar` 묶음을 따로 만들면 더 좋습니다. 연결은 `.arena[data-motion='push'] [data-sprite='boss1'][data-pose='strike']`처럼 합니다.

## 3. 종목 도구 그림 (작은 아이콘, 투명 PNG→webp)

지금은 CSS 도형입니다(`style.css`의 `.prop-ddakji` 등). 그림이 오면 `background: url(...) center/contain no-repeat`로 바꿉니다.

| 파일 | 크기 | 내용 |
|---|---|---|
| `prop-ddakji.webp` | 48×48 | 빨강·파랑으로 접은 종이 딱지 |
| `prop-eraser.webp` | 48×28 | 반은 흰색, 반은 파란 종이에 싸인 지우개 |
| `prop-dodgeball.webp` | 48×48 | 빨간 피구공 |
| `prop-basketball.webp` | 48×48 | 농구공 |

다음 종목용으로 아래도 함께 그려 주세요(지금 코드에서는 아직 안 날아감).

- `prop-satba.webp`: 씨름 샅바
- `prop-headgear.webp`: 태권도 헤드기어
- `prop-glove.webp`: 스파링 글러브

## 4. 먼지 구름·의성어 연출 시트

- `fx-dust.webp`: 가로 6프레임 시트(각 160×120). 몽글몽글한 흰·베이지 먼지 구름이 퍼졌다 사라집니다. 만화의 '와다닥' 먼지 느낌입니다.
  - 연결: `.impact.fx-dust::before`의 배경을 시트로 바꾸고 `steps(6)`로 돌립니다.
- `fx-cloud.webp`: 같은 규격입니다. 팔·다리가 삐죽 나온 **코믹 싸움 구름**(둘이 엉켜 먼지 속에서 뒹구는 만화 표현)이고, 코믹 밀치기·씨름·유도에 씁니다.
- 의성어 글자 그림(선택): `딱!`·`통!`·`슛!`·`영차!`·`얍!`·`한판!`·`끄응!`·`뿅!`. 지금은 메이플스토리체에 빨간 외곽선 글자로 나옵니다. 손글씨 만화 글자 그림이 있으면 교체합니다.

- **교복 버전 주인공:** 중학교는 하복이나 생활 체육복, 고등학교는 교복 재킷을 입힌 boy·girl 서 있는 그림 2장씩입니다. `boy-middle.webp`·`boy-high.webp`처럼 만들어 주세요.
  - 연결은 Claude가 합니다(`state.cycle`로 바꿈).
- **배경:** 중학교 체육관·씨름장(모래판), 고등학교 태권도장·스파링 링·농구 코트. 각 535×302, `map-m01~`·`map-h01~`로 맵 18개 중 원하는 만큼 그려 주세요. 4~6장이어도 됩니다.
  - 연결은 Claude가 합니다.

## 6. 표지와 첫 화면

- `cover.webp` 다시 그리기: 지금 두 아이가 주먹을 쥐고 맞서는 그림입니다.
  - 바꿀 그림: 운동장에서 **딱지치기 한판 승부**를 하는 장면입니다. 한 아이는 딱지를 높이 들어 내리치려 하고, 다른 아이는 신나서 웃으며 바닥의 딱지를 가리킵니다.
  - 배경은 지금처럼 벚꽃과 학교 건물로 두고, 뒤에서 반 친구들이 응원합니다.
- `hero.webp`도 주먹 자세라면 같은 원칙으로 바꿔 주세요.
