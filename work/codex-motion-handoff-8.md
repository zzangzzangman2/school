# 해솔 격투 아카데미 8차 모션 인수인계

수정된 모션 WebP와 반복 GIF는 각각 30개다. 주인공 장비 마스크 1개와 건달 정지 그림 12개도 같이 교체했다. 모든 프레임의 크기는 280×255px이다. [8차 요청서](codex-motion-request-8.md)

| 변경 | 프레임과 검수 기준 |
| --- | --- |
| 동료 달리기 16명 | 4칸. 오른발 접지 → 공중 교차 → 왼발 접지 → 공중 교차. 접지선은 249px, 공중의 발은 244px. 오다솜은 이전 8개 그림 중 이 순서에 맞는 4개를 사용했다. |
| 건달 쓰러짐 12명 | 4칸. 3·4번째의 상체와 머리는 기존 무릎 자세에서 키우고 접힌 하체의 높이를 조정했다. 키는 서 있을 때의 약 60% → 57%. 마지막 칸을 기존 정지 그림에도 썼다. |
| 유세린 공격 | 3번째 타격 칸에서 칼날 끝만 안으로 옮겼다. 몸과 발 위치는 기존과 같다. |
| 건달 3 머리 여백 | 2번째 칸 위에 10px의 여백을 뒀다. 같은 동작에서 여백이 부족했던 나머지 건달도 정렬했다. |
| 주인공 굳히기 | 7칸. 서기 → 몸 낮춰 잡기 → 한쪽 무릎 대기 → 바닥에서 누르기로 이어진다. 7칸 장비 마스크와 재생 코드의 4번째 타격 칸도 반영했다. |

- 새 배치는 `work/recess/assets`, 확인용 GIF는 `outputs/recess-motion-preview-8`에 있다.
- `outputs/recess-motion-pack-8.zip`에 바뀐 그림, 마스크, GIF를 모았다. 단일 HTML도 새 리소스로 다시 묶었다.
- 내장 이미지 생성 도구로 기존 동료 얼굴·복장 참조를 사용해 달리기의 네 자세를 그렸다. 주인공 굳히기의 두 중간 자세에도 같은 도구를 사용했다. 편집 기준은 기존 그림의 피부·의상·채색이다. 건달의 무릎 자세와 펜싱 칼끝은 기존 그림을 정렬·보정했다.
- 제작 작업은 `work/build_recess_motion8.py`에 있다. `--raw`에 프롬프트별 생성 원본이 있는 폴더를 넘기면 다시 제작한다.
