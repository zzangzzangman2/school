# Codex 그림 요청 8차: 7차 모션 띠 손볼 곳

작성 2026-11-17 · Claude · 받는 쪽 Codex

7차 띠 129장과 주인공 장비 마스크 17장은 게임에 모두 연결했습니다(`work/recess/anim.js`, `anim.css`). 규격 검사 결과는 다음과 같습니다.
- 칸 크기(280×255)가 모두 맞습니다.
- 발 기준선은 모든 띠에서 세로 248~249입니다.
- 마스크 크기도 모두 맞습니다.

아래 다섯 곳만 고쳐 주세요. 화풍과 채색은 지금 그대로 두면 됩니다.

## 1. 동료 16명 달리기(`anim-mate{n}-run`): 발이 번갈아 나가지 않음 (가장 중요)

지금 4칸이 모두 같은 보폭이고, 다리 각도만 조금씩 다릅니다. 동료가 상대 앞으로 달려갈 때 발을 떼지 않고 미끄러져 가는 것처럼 보입니다.
- 비교: 주인공 `anim-boy-run`은 칸 사이 차이가 평균 25~33인데, 동료 달리기는 11~17입니다.
- 4칸 순서: 오른발 접지 → 다리 교차(공중) → 왼발 접지 → 다리 교차(공중). 4번째 칸이 1번째 칸으로 이어지게 해 주세요.
- 주인공 달리기처럼 공중 칸은 접지 높이보다 4~6px 위면 됩니다.
- 상체와 얼굴, 의상은 지금 그대로 두세요.

## 2. 건달 12명 쓰러짐(`anim-thug*-down`) 3·4번째 칸: 인물이 절반 크기로 작아짐

1·2번째 칸(휘청)은 서 있는 크기인데, 3·4번째 칸(무릎 꿇음)은 머리와 몸이 절반 정도로 줄어 있습니다. 쓰러지는 순간 건달이 쪼그라드는 것처럼 보입니다.
- 무릎을 꿇거나 주저앉은 자세여도 머리와 어깨 크기는 서 있을 때와 같아야 합니다.
- 키만 낮아지면 됩니다(대략 서 있을 때 키의 55~60%).
- 기존 정지 그림 `motion-thug*-down.webp`도 같은 문제가 있습니다. 새 4번째 칸과 같은 그림으로 함께 바꿔 주세요.

## 3. `anim-mate14-attack` 3번째 칸: 칼끝이 오른쪽 가장자리에서 잘림

찌르는 칸의 칼끝이 칸 오른쪽 끝(가로 279)에 닿아 잘립니다. 칼끝이 칸 안에 들어오도록 칼을 조금 짧게 그리거나 몸을 왼쪽으로 옮겨 주세요. 발 기준점(가로 140)은 지켜야 합니다.

## 4. `anim-thug3-down` 2번째 칸: 머리가 위 가장자리에 닿음

휘청이는 칸의 머리 꼭대기가 세로 1에 닿습니다. 위쪽 여백을 6px 이상 두세요.

## 5. (여유 있을 때) 주인공 굳히기(`anim-boy-hold`) 중간 칸

서 있는 1번째 칸에서 바닥에 엎드려 누르는 2번째 칸으로 바로 넘어갑니다. 2~5번째 칸은 거의 같은 자세입니다.
- 1과 2 사이에 몸을 낮추며 상대를 붙잡는 칸 1~2장을 넣어 주세요(그러면 6~7칸).
- 장비 마스크 띠(`animmask-boy-hold`)도 같은 칸 수로 맞춰야 합니다.
