# 현재 게임 소스

`index.html`을 브라우저로 열어 실행합니다. 진행은 브라우저에 저장됩니다. 배포 파일은 프로젝트 루트에서 `py -I work/package_recess.py`로 만듭니다.

## 기능과 파일

| 파일 | 역할 |
| --- | --- |
| `game.js` | 전투·보상·성장·저장 복구·동료·도전·시즌 규칙 |
| `ui.js` | 전투 화면·이동·보상·메뉴·입력 |
| `meta-ui.js` | 동료·상점·편성·시험용 동작 확인 |
| `live-ui.js` | 도장·시즌·동료 원정·도감·저장 파일 이어 하기 |
| `season-calendar.js` | 시즌 일정·경기 규칙·보상표 |
| `anim.js`, `anim.css` | 모션 띠 재생과 이미지 연결 |
| `wardrobe.js`, `wardrobe.css` | 장비 색 적용과 주인공 모션 마스크 |
| `style.css`, `assets.css`, `motion.css` | 화면 배치·배경·원화·정지 동작 연결 |

아카데미 12경기장 졸업 뒤 24지역을 제패합니다. 자동 전투에서 패배하면 같은 맵을 수련하고 보스에게 바로 다시 도전할 수 있습니다. 장비는 장착과 강화가 가능하고 주인공의 옷 색에 반영됩니다.

방치는 기본 12시간, 명예 코칭으로 최대 16시간 계산합니다. 자동 훈련을 켜면 방치와 빠른 휴식에도 적용됩니다. 일일 목표·주간 대회·도장 30층·기록전 무료 연습·동료 원정·도감과 시즌이 있습니다.

## 이미지

이미지는 `assets/`에 있습니다. `stand-mate1.webp`~`stand-mate16.webp`는 720×1280 투명 전신, 전투 그림 한 칸은 280×255입니다. 모션 띠는 칸을 가로로 이어 붙이고 발 기준은 (140, 249)에 맞춥니다.

여성 캐릭터는 만 20세 이상 성인으로, 귀여움·예쁨·청순함·섹시함과 얼굴·체형·의상을 다양하게 구성합니다. Nikke DB의 실제 원화를 열어 피부·눈·머리카락·소재의 표현을 확인합니다. [Nikke DB](https://nikke-db.pages.dev/)

그림 추가 요청은 [Gemini 요청서](../gemini-art-brief.md), 세부 모션 규격은 [9차 인수인계](../docs/art/codex-motion-handoff-9.md)에 있습니다.

## 배치와 모션

그림자 기사단 v55의 대형을 참고해 주인공 앞에 동료가 깊이를 달리해 서고, 적도 여러 자리에 분산됩니다. 주인공·동료·일반 적은 같은 크기 기준을 사용하고 보스에는 1.15배를 적용합니다. 적이 한 명 쓰러져도 남은 적의 자리는 유지됩니다.

주인공 원본 띠와 마스크를 고친 뒤 `../tools/smooth_strip.py`로 보간합니다. 대기·달리기는 `--loop`를 쓰며 원본 6칸 이하는 `--k 5`, 7~8칸은 `--k 4`, 9칸은 `--k 3`입니다. `anim.js`의 `ANIM_IMPACT`는 원본의 0부터 세는 타격 칸입니다.

## 시즌 운영

날짜는 한국 시간 0시 기준입니다. `ends`부터 경기와 점수 획득이 끝나고, `claimUntil`부터 보상 수령이 닫힙니다. 이미 참여한 시즌의 규칙·보상 버전과 수령 이력은 저장됩니다.

웹 배포 시 같은 폴더의 `season-calendar.json`에 `season-calendar.js`와 같은 배열 형식을 제공하면 일정을 갱신합니다. 다른 이름·일정·경기·보상을 등록하면 다음 시즌으로 이어집니다.

설정에서 저장 파일을 내보내고 새 기기의 첫 화면에서 불러올 수 있습니다. 서버 계정 동기화와 서버 기준 시간은 서비스 배포 작업에 포함됩니다.
