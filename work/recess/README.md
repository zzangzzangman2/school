# 쉬는 시간의 왕!

스무 살 해솔 격투 아카데미 신입생이 4학년 과정을 마치고 전국 24개 지역에 도전하는 세로형 방치 RPG입니다. 첫 화면에서 선수와 닉네임을 정합니다.

압축을 푼 뒤 `index.html`을 브라우저로 열면 시작합니다. 게임 파일을 같은 폴더에 두세요. 진행 상황은 실행한 브라우저에 저장됩니다.

- `game.js`에서 아카데미 12개 경기장, 지역과 종목, 상대, 보상, 훈련 비용, 전공 보너스를 수정할 수 있습니다.
- `ui.js`에는 지도, 캐릭터 선택, 저장 코드가 들어 있습니다.
- `style.css`는 화면 스타일입니다. `assets.css`와 `motion.css`는 배경과 자세에 그림을 연결합니다. `wardrobe.js`는 `wardrobe.css`에 연결된 부위별 마스크로 장착한 옷과 가방을 그립니다.
- `anim.js`는 `anim.css`(건달·동료)와 `wardrobe.css`(주인공)에 연결된 모션 띠를 한 칸씩 그립니다.

자동 대결에서 코인과 장비를 얻고 훈련과 장비로 실력을 올립니다. 첫 장비는 대결 화면에서 바로 장착할 수 있습니다. 1-3 대표 다온은 방어 뒤 반격합니다. 공 울림 카운터는 방어를 깨고, 돌진 스트레이트는 반격 뒤 빈틈에 피해를 더 줍니다. 브라우저를 닫은 동안의 대결은 다시 열 때 최대 4시간까지 계산합니다.

지면 같은 장소에서 반복 수련을 시작합니다. 수련도 전투 보상을 주며, 3승 후 원래 대결을 다시 시도합니다. 각 맵에서 4승마다 지도에 표시된 장비가 나옵니다. 중복 장비는 천 조각으로 바뀌고, 가방에서 장비를 최대 +5까지 강화할 수 있습니다. 목표 탭에서도 코인과 천 조각을 받을 수 있습니다. 가방에서 상의, 하의, 가방, 신발을 장착하면 전투 자세마다 해당 부위의 색과 무늬가 함께 적용됩니다.

## 성인 아카데미 일러스트

설정의 **선수 로비**에서 전신 일러스트를 볼 수 있습니다. 상점의 **스킨 미리보기**는 기본 훈련복을 보여 줍니다. 대화 탭에는 준비 중 안내가 표시됩니다. 타격, 잡기, 태권도는 각 경기용 스프라이트를 사용합니다.

여성 캐릭터를 새로 그리거나 리터치할 때는 **[Nikke-DB](https://nikke-db.pages.dev/) 원화를 반드시 확인**합니다. 피부의 반사광과 윤기, 눈과 머리카락, 의상 소재, 조명, 선화, 채색, 비율과 포즈까지 참고합니다. 초안과 완성본을 각각 대조하고 해솔 아카데미 인물과 의상은 새로 디자인합니다. 밝은 파스텔 채색의 추가 레퍼런스는 [솔린: 프로스트 티켓 원화](https://www.gamey.kr/news/articleView.html?idxno=3015183)입니다.

## 2026-11-18 주인공 매끄러운 모션 띠(칸 사이 보간) (Claude)

- **왜 끊겨 보였나**: 화면은 초당 60번 그리지만, 모션 띠가 동작마다 3~7칸이고 초당 약 7~13칸으로 재생돼 그림이 바뀌는 순간이 보였습니다.
- **주인공 먼저 적용**: 원래 칸 사이마다 5칸을 광학 흐름(OpenCV DIS)으로 끼운 띠를 새로 만들었습니다.
  - 처음에는 3칸이었는데, 더 다듬으면서 5칸으로 늘렸습니다. 7칸은 띠 하나가 13,000px을 넘어 장비 색 띠가 동작마다 약 14MB를 메모리에 올리므로 쓰지 않았습니다.
  - 주인공 띠 17개(예: 펀치 6칸 → 31칸)와 장비 마스크 17개가 `assets/anim-boy-<동작>-smooth.webp`, `assets/animmask-boy-<동작>-smooth.webp`에 있습니다.
  - 두 그림을 겹쳐 섞으면 반투명 잔상이 생겨서, 가까운 원래 칸 하나만 흐름대로 휘어 씁니다. 흐름은 부드럽게 다듬어 그림이 찢어지지 않게 했습니다.
  - 마스크는 같은 흐름으로 휩니다. 가장 가까운 점을 가져오고(부위 색이 섞이지 않음) 손실 없이 저장해서, 장비 색이 그림과 어긋나지 않습니다.
  - 만드는 도구는 `work/tools/smooth_strip.py`입니다(`--k 5`, 반복 띠는 `--loop`, `--mask`).
- **재생**(`anim.js`의 `SMOOTH_K`, `animSmooth`, `smoothOn`): 동작 계획(칸 번호)은 원래 띠 기준 그대로이고, 재생할 때 매끄러운 띠의 칸으로 옮깁니다.
  - 여러 칸 구간은 다음 상태로 이어지는 사이 칸까지 이어서 재생합니다.
  - 타격 칸은 그 칸 그대로 둬서 엔진의 타격 순간과 맞습니다. 마무리는 타격 칸 바로 뒤 사이 칸부터 재생합니다.
  - 대기·달리기 반복은 마지막 칸 → 첫 칸 사이도 메웠습니다. 초당 칸 수는 6배입니다(대기 7 → 42).
- **동작이 바뀌는 순간**(`ANIM_BLEND_MS` 70ms): 앞 동작의 마지막 그림을 잠깐 겹쳐 지워 툭 바뀌지 않게 합니다.
  - 맞는 순간(→ 맞음)은 바로 바꿉니다.
  - 타격 칸이 오면 겹쳐 지우기를 끝내서 타격 그림은 또렷합니다.
- **몸 이동**(`style.css`의 `.fighter.player .sprite`): 상태마다 가속·감속을 달리했습니다.
  - 돌진은 빠르게 나갔다 부드럽게 멈춥니다.
  - 타격은 0.05초에 꽂히며 살짝 눌리고, 맞으면 늘어나며 밀립니다.
  - 대기로는 0.24초에 미끄러지듯 돌아옵니다.
- **타격 잔상**(`heroTrail`): 타격 순간에 바로 앞 자세를 반투명하게 0.2초 남깁니다.
- 몸 이동과 잔상은 주인공에만 적용했고, 다른 선수는 그대로입니다.
- 칸 번호는 원래 띠 기준으로 알립니다(`data-frame="boy:punch:2.25"`, 사이 칸은 소수).
- 테스트 모드 → 테스트 도구 → **주인공 매끄러운 띠 켜기/끄기**로 원래 띠와 바로 견줘 볼 수 있습니다. 모션 띠 보기(동작 확인)는 원래 띠를 보여 줍니다.
- 동료·건달은 아직 원래 띠입니다. 주인공이 괜찮으면 같은 도구로 넓힙니다(동료 16명 × 띠 4종, 묶음 파일이 더 커짐).
- 묶음 파일은 약 39MB → 45MB입니다.
- **Codex 요청 9차**(`work/codex-motion-request-9.md`)
  - 칸 사이가 40px 넘게 움직여 보간이 약한 곳(발차기·무릎·연타·돌진·굳히기·메치기·반격·쓰러짐)에 중간 칸을 그려 달라고 했습니다.
  - 맞음 3칸 → 5칸, 대기 숨 고르기를 더 크게(지금 칸 사이 1~2px라 뻣뻣함) 요청했습니다.
  - 장비 마스크의 상의·하의 경계를 허리 가로선이 아니라 옷 모양대로(재킷 자락이 바지 색으로 칠해짐) 고쳐 달라고 했습니다.
  - 새 동작 일어나기(`getup`)도 요청했습니다.
  - 받으면 `smooth_strip.py`로 매끄러운 띠를 다시 만들고, 타격 칸 번호(`ANIM_IMPACT`)를 맞춥니다.

## 2026-11-18 방치 상한 12시간·빠른 휴식, 아카데미 학년별 길이, 하단 패널 문구 정리 (Claude)

유명 방치형 게임 15종과 대조한 결과(`work/idle-games-feature-benchmark.md`)에서 먼저 고른 것입니다.

- **방치 상한**(`OFFLINE_LIMIT`): 4시간 → **12시간**입니다. 명예 코칭 '숙소 휴식'으로 최대 16시간까지 늘어납니다.
  - 쉬는 시간 보상의 코인 2배 값은 방치 4시간마다 보석 50입니다(`offlineDoubleCost`). 4시간까지 50, 8시간까지 100, 12시간까지 150입니다.
- **빠른 휴식**(`QUICK_REST`, `quickRest`)
  - 대결 탭 맨 위 카드입니다. 2시간 동안의 대결(코인·경험치·장비·진행)을 바로 받습니다.
  - 하루 4번이고, 첫 번은 무료, 다음은 보석 50·100·150입니다. 한국 시간 0시에 다시 채워지고, 기기 시계를 되돌려도 다시 차지 않습니다.
  - 특별 대회 중에는 쓸 수 없습니다.
  - 무료가 남아 있으면 대결 탭에 빨간 점이 뜨고, 오늘 화면 바로 가기에 '빠른 휴식 · 2시간치 무료로 받기'가 나옵니다.
  - 측정해 보면 2시간에 약 1,050번 이깁니다. 하루 2시간을 더 하는 셈인 밸런스 시뮬(하루 18시간)에서 첫 주 최고 진행은 1~4% 빨라지고, 3달부터는 같습니다.
- **아카데미 학년별 길이**(`ACADEMY_PACE`, `paceMult`)
  - 전에는 훈련 없이 10분, 자동 훈련이면 4분에 졸업했습니다(학년마다 1분).
  - 이제 1-1·2-1·3-1·4-1·4-3 자리의 상대 체력 배율이 12·14·20·14·15이고, 사이 맵은 같은 비율로 이어집니다. 학년마다 보스에서 막히고, 반복 수련·훈련으로 넘어갑니다.
  - 실제 대결 엔진으로 재면(자동 훈련) 1학년 14분 → 2학년 21분 → 3학년 53분 → 4학년 66분이고, 졸업까지 약 2.6시간입니다. 동료 1명을 출전하면 약 2.1시간입니다. 훈련을 안 하면 3학년에서 막힙니다.
  - 3학년 배율은 맵을 지날수록 줄지만, 다음 맵 상대가 앞 맵보다 약해지지 않는 범위입니다.
  - 코인·경험치는 승리마다 주므로 졸업할 때 실력은 크게 다르지 않습니다.
  - 졸업 뒤 첫 지역(3바퀴·36맵)을 도는 동안 배율이 ×1로 서서히 돌아와, 갑자기 쉬워지지 않고 그 뒤 성장은 그대로입니다.
  - 밸런스 시뮬(하루 16시간)은 첫날 최고 진행 183 → 125(제패 지역 5곳 → 3곳), 둘째 날 250 → 223입니다. 1주부터는 거의 같고(325 → 320), 2년 시점은 617로 같습니다.
- **결과 창 순서**: 졸업·제패 축하 창이 쉬는 시간 보상·빠른 휴식 결과 창을 닫지 않고, 그 창을 닫은 다음에 뜹니다(`showSchool`).
- **하단 패널 문구 정리**: 다른 방치형 게임처럼 숫자와 버튼 위주로 바꿨습니다.
  - 제목 아래 설명 줄은 숨기고 제목 옆 '?' 버튼으로 옮겼습니다(`bindSectionHelp`, `helpButton`). 상태를 보여 주는 줄(동료 출전·보유 효과, 스티커 도감 효과)만 남겼습니다.
  - 빠른 휴식 카드: '2시간' 칩과 남은 횟수 점입니다.
  - 주간 카드: 규칙 한 줄(이번 주 규칙·추천 계열 인원), 남은 날짜 D-n입니다. 점수 설명과 기간은 '?'로 옮겼습니다.
  - 훈련 줄은 '파워 +4 · ×2까지 25'처럼, 업적 줄은 보상만, 기록전은 '구간 · 다음까지 피해'만 보여 줍니다.
  - 시너지 없음 안내와 자동 훈련 설명은 한 단어로 줄였습니다.
- 검사
  - check_recess_meta.py: 12시간 상한, 빠른 휴식(무료 → 보석 50 → 부족 → 다 씀), 오늘 화면 바로 가기를 확인합니다.
