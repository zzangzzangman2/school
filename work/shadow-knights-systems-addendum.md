# 그림자 기사단 v55 추가 기능 분석

PC에 보관한 v55 APK의 Unity 데이터와 ARM64 함수 호출을 확인하고, 현재 해솔 코드와 대조했습니다. 아래의 해솔 적용안은 신규 설계입니다. 그림자 기사단의 동작은 APK에서 확인한 범위로 적었습니다.

## 1. 최고 피해 기록을 쓰는 사냥

**그림자 기사단에서 확인한 동작**

- 사냥에는 일일, 경험치, 그림자 장비 모드가 있습니다. 일일·경험치 모드의 기록 갱신 함수는 저장된 피해량과 이번 피해량 중 큰 값을 남깁니다.
- 소탕 버튼은 남은 입장 조건과 최고 피해 기록을 확인합니다. 일일·경험치 소탕의 일부 보상 경로에서는 최고 피해량에서 테이블의 적 체력을 순서대로 빼면서 도달한 구간의 보상을 더합니다. 그림자 장비 사냥에는 별도 피해 기록·최고 단계와 장비 보상표가 있습니다.

**해솔 적용안**

상금 토너먼트에 **30초 기록전**을 추가합니다. 주인공과 출전 동료의 실제 유효 피해량을 합산하고 결과창에 `이번 기록`, `개인 최고`, `다음 보상까지 남은 피해`를 표시합니다. 소탕은 저장된 최고 보상 구간을 사용합니다. 동료를 바꾸거나 장비를 강화했을 때 점수가 달라져 재도전할 이유가 생깁니다.

기존 토너먼트의 단계·소탕 진행은 `state.dungeons`에 있습니다. 기록전은 별도 최고 기록으로 관리하고 입장권을 쓰는 시점과 보상 지급을 한 트랜잭션으로 처리합니다. 체력 비례 기술은 제한된 최대 체력 또는 기록전용 상한으로 계산하고, 대상의 남은 체력을 초과하는 피해는 점수에서 제외합니다.

근거는 `HuntingDailyManager.TryChangeTotalDamage`, `HuntingDailyManager.TryGetSkipReward`, `TBL_HUNTING_EXP.Health`, `TBL_HUNTING_DAILY.Health`, `HuntingShadowEquipmentManager.TryGetSkipReward`입니다.

## 2. 재입학 후 이전 지역까지 복귀 가속

**그림자 기사단에서 확인한 동작**

- 환생은 피버 플래그와 종료 스테이지를 설정합니다. 종료 지점은 직전 월드의 시작 스테이지와 환생 돌진 숙련 보정을 이용합니다. 전투는 현재 스테이지가 종료 지점 전일 때 피버 상태에 들어가며 군주와 동료는 전용 이동 상태를 씁니다.
- APK에서는 환생 전 화면에 현재 스테이지, 피버 스테이지, 획득할 환생석을 표시하는 필드를 확인했습니다.

**해솔 적용안**

재입학 확인창에 **빠른 복귀 종료 지점**을 표시합니다. 이미 통과한 초반 구역에 기존 배속과 짧은 라운드 연출을 적용하고, 재입학 전 최고 진행에 가까워지면 보통 전투로 전환합니다. 현재 재입학은 아카데미 정문부터 시작하므로 시골 구역을 여러 바퀴 돌았던 플레이어에게 효과가 큽니다. 가속 중 이긴 맵은 정상 진행으로 반영하되 최초 제패 보상은 기존 최고 기록으로 판정합니다. 종료 지점과 남은 구간은 새로고침·오프라인 복귀 후에도 맞아야 합니다.

근거는 `PlayerManager.Rebirth`, `CalculateFeverWorld`, `MasteryStat.RebirthDashStage`, `BattleManager.IsFever`, `KingObject.Fever_Update`입니다.

## 3. 지역 규칙과 추천 동료

**그림자 기사단에서 확인한 동작**

- 월드 진행 카드가 종족별 강화·약화 대상과 수치, 추천 영웅, 출현 영웅 목록을 읽습니다. 스테이지 시작 경로에는 월드별 웨이브 공격·체력 계수를 읽는 호출이 있습니다.
- 종족 이름을 가진 던전 세 종류에 본편과 별도의 선택 목록이 있고, 진입 화면에서 자동 편성과 수동 교체를 지원합니다.

**해솔 적용안**

도장에 들어가기 전에 **경기 규칙, 추천 동료와 추천 이유**를 한 줄씩 보여줍니다. 예를 들어 여러 상대가 나오는 경기에는 강아린의 광역 차기, 대표 보스 경기에는 서리나의 보스 추가 피해, 거센 연타가 나오는 경기에는 한서아의 보호막이나 이수안의 회복을 표시합니다. 시골 지역에서 같은 경기를 여러 바퀴 돌 때 바퀴마다 규칙 하나를 바꿔 편성 선택에 의미를 줍니다. 처음에는 소프트 추천과 소폭 가산점을 적용하고, 규칙 특화 이벤트에서 별도 편성을 쓸 수 있습니다.

근거는 `UI_WorldMapProgressSlot.Set`, `TBL_WORLD`의 강화·약화 및 추천 필드, `Dungeon.ShadowPicks`, `UI_DungeonShadowPick.AutoPick`입니다.

## 4. 던전 자동 다음 단계와 결과 묶음

**그림자 기사단에서 확인한 동작**

- 던전 종료 코드가 자동 다음 단계 설정과 최대 층을 검사하고, 조건을 충족하면 같은 던전의 다음 도전을 호출합니다.
- 던전은 층, 소요 시간, 처치 수, 보상의 기록을 저장합니다. 성공 결과 UI는 층별 기록 목록을 받아 보상을 묶으며 자동 닫기 경로도 있습니다.

**해솔 적용안**

이벤트전 카드에 **승리하면 다음 단계**를 선택할 수 있게 합니다. 열쇠가 있고 이번 단계에 이겼을 때만 바로 다음 단계로 이어가며, 실패·열쇠 소진·중지 때 결과를 한 번에 보여줍니다. 기존 `enterDungeon`의 입장 검사와 `leaveDungeon`의 승리 시 열쇠 차감을 재사용합니다. 2회 승리 후 열쇠가 정확히 2개만 줄고 실패는 차감하지 않는지 확인합니다.

근거는 `BattleManager.OnDungeonEnd`, `DungeonManager.AutoNext`, `DungeonRecord`, `UI_DungeonResult.OpenSuccess`, `UI_DungeonResult.SetRewards`입니다.

## 추가로 확인한 기능

- **토벌 보관함**. 별도 토벌 전투 관리자와 보상 슬롯 한도, 누적 보상 일괄 수령을 확인했습니다. 해솔에서는 비출전 동료의 원정 보상함으로 응용할 수 있습니다. 토벌 화면을 벗어난 상태의 동작은 플레이 검증이 필요한 항목입니다.
- **유물 승급**. 승급에 필요한 중복 수를 검사하고, 성공하면 다음 등급에서 선택한 유물의 개수를 올리는 호출을 확인했습니다. 해솔에서는 이미 장비 중복을 천 조각으로 바꾸고 동료 중복을 성급업에 사용합니다.
