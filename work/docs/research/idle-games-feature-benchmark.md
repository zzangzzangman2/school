# 유명 방치형 게임 15종 기능 대조 (2026-11-18, Claude)

유튜브 광고·후원으로 유명한 방치형 게임 15종에 어떤 기능이 있는지 조사해서 「쉬는 시간의 왕」과 대조했습니다.

**조사 대상**

| 갈래 | 게임 |
|---|---|
| 한국 '키우기' 계열 | 세븐나이츠 키우기, 버섯커 키우기, 레전드 오브 슬라임, 카피바라 GO, 소드마스터 스토리 |
| 영웅 수집형 | AFK 아레나, AFK 저니, 아이들 히어로즈, 히어로 워즈, 레이드: 그림자의 전설 |
| 탭·로그라이크·미소녀 수집형 | 탭 타이탄 2, 아이들 슬레이어, 궁수의 전설 2, 니케(방치 보상·호감도 쪽만), 라그나로크 아이들 어드벤처 |

**조사 방법**
- 영상은 보지 않았습니다. 스토어 설명, 공식 패치 노트, 나무위키·팬 위키, 공략·기사만 읽었습니다.
- 일부 위키는 접속이 막혀 근거가 약한 곳이 있습니다.
- 표의 "확인" 수는 출처로 확인된 게임 수입니다. 실제로는 더 많을 수 있습니다. 특히 출석, 우편, 일괄 받기, 빨간 점 같은 편의 기능은 문서에 잘 안 나와서 적게 잡혔습니다.

## 2. 우리에게 없는 것: 넣는다면 이 순서

서버 없이 만들 수 있고 많은 게임이 공통으로 가진 것부터 적었습니다.

1. **무한 탑**(10/15종)
   - 층마다 상대가 세지고, 층 보상과 10층마다 큰 보상을 줍니다.
   - 열쇠 없이 하루 종일 도전합니다. 막히면 성장하고 다시 옵니다.
   - 이름 예: 「아카데미 승단 계단」. 던전과 달리 하루 제한이 없어 막혔을 때의 목표가 됩니다.
2. **기간 한정 이벤트 + 픽업 모집 + 달력**(13/15종, 픽업 4종)
   - 이미 다음 차례로 잡힌 '달력 시즌'과 합칩니다.
   - 2주짜리 이벤트를 열고, 이벤트 점수로 보상을 줍니다. 그 기간 픽업 동료의 확률을 올립니다.
3. **컴퓨터 상대 아레나**(10/15종이 PvP)
   - 서버 대신 가상 선수 사다리를 둡니다(소드마스터 AI 대전 방식).
   - 하루 입장 5번, 순위 구간 보상, 주간 시즌으로 운영합니다.
   - 상대는 내 진행도 근처에서 만든 주인공과 동료 편성입니다.
4. **방치 상한 늘리기 + 즉시 방치 보상**
   - 상한은 4시간 → 12시간을 제안합니다(코칭으로 최대 16시간).
   - '빠른 휴식'은 2시간치를 바로 받고, 하루 첫 회 무료, 이후 보석입니다. AFK·니케 방식입니다.
5. **동료 호감도·대화**(니케 방식)
   - 대화 탭이 이미 비어 있습니다.
   - 출전·선물로 호감도가 오르고, 단계마다 짧은 대화와 능력치를 줍니다. 최고 단계에서 전용 스킬이 강해집니다.
   - 미소녀 수집형의 핵심이고, 대사는 Codex 또는 사용자가 정합니다.
6. **S 천장 + 모집 위시리스트**
   - 모집 100회 안에 S 확정 마일리지를 두고, 원하는 S 동료 2명을 찍어 두면 그 안에서 나오게 합니다.
7. **로그라이크 버프 모드**(6/15종)
   - 「연습 리그」: 5판마다 버프 3개 중 하나를 고르며 끝까지 갑니다. 주 단위로 초기화합니다.
8. **파견(원정)**: 출전하지 않는 동료를 4~8시간 보내 재화를 받습니다. 운영 문서의 다음 단계와 같습니다.
9. **동료 레벨 공유(공명)**: 가장 높은 동료 4명의 레벨을 나머지에게 맞춥니다. 16명을 일일이 올리는 부담을 줄입니다.
10. **편성 프리셋**: 주간 규칙 3종에 맞춰 편성 3개를 저장합니다.
11. 작은 것들
    - 쿠폰 코드
    - 누적 모집 보상(50·100·200회)
    - 대결 기여도 표(세나키 대미지 미터기처럼 주인공과 동료별 피해 비율)
    - 진행 달성 패키지
12. **미니게임**: '쉬는 시간'이라는 이름에 잘 맞습니다(딱지·팔씨름 같은 짧은 놀이). 그림이 필요해서 Codex와 함께 해야 합니다.
13. **보조 수집 축(펫 대신 응원 마스코트 등)**: 그림이 많이 필요합니다.

**넣지 않는 쪽을 권하는 것**
- VIP 등급: 리뷰에서 과금 압박 불만이 반복됩니다.
- 서버가 필요한 길드·실시간 PvP·채팅·협동·순위표: 지금 구조에서는 만들 수 없습니다.

## 3. 이미 장르 표준을 갖춘 것

다음은 이미 있습니다. 일부는 대형 게임보다 앞선 부분도 있습니다.
- 자동 전투, 보스 관문, 반복 수련, 배속, 자동 스킬
- 훈련, 장비 강화, 스킬 강화, 승급, 환생
- 도감 효과, 업적
- 동료 뽑기, 조각 성급업, 계열 시너지
- 재화 던전, 소탕, 연속 도전
- 혼자 하는 피해량 측정(기록전)
- 오늘 목표, 주간 대회, 출석, 우편, 가이드 퀘스트
- 월정액, 광고 제거 상품, 칭호

환생 뒤 빠른 복귀(×3)와 주간 규칙에 맞는 추천 계열은 조사한 게임에서는 드물었습니다.

  - 대형 콜라보

- **카피바라 GO**

- **소드마스터 스토리**
  - 위시리스트 모집, 120회 천장
  - 3배속
  - 2주 시즌 콜로세움(공격·방어 덱)
  - 레이드·바운티·어비스
- **AFK 아레나**
  - 공명 수정(상위 5명 레벨 공유)
  - 2시간치 즉시 방치 보상(하루 3회)

  - 격주 로그라이크 미궁

  - 시즌마다 새로 쌓는 성장
  - 서버 피해량 경쟁 보스(꿈의 영역)
  - 같은 조건으로 붙는 PvP
- **아이들 히어로즈**
  - 제단(영웅 분해 환급)
  - 550층 탑
  - 선술집 파견, 카지노 룰렛
  - 자동전투 골드 2배 구독
- **히어로 워즈**
  - 타이탄과 길드전
  - 3팀 그랜드 아레나
  - 층마다 버프가 쌓이는 탑
  - 광고로 에너지·재화
- **레이드: 그림자의 전설**

  - 탑 자동 오르기(보스층에서 멈춤)
  - 결과를 먼저 보고 열쇠를 쓸지 정하는 빠른 전투
  - 에너지 2배 = 보상 2배
- **탭 타이탄 2**
  - 환생 → 유물 → 아티팩트 97종 루프
  - 4갈래 스킬 트리
  - 클랜 레이드, 카드
