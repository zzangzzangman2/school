# 해솔 격투 아카데미 6차 그림 인수인계

[니케 DB 갤러리](https://nikke-db.pages.dev/gallery)의 눈매, 표정, 피부의 따뜻한 반사광, 머리카락 윤기와 의상 소재를 참고해 동료 16명을 ImageGen으로 그렸습니다. 동료마다 얼굴형, 눈꼬리, 눈썹, 입매와 헤어 실루엣을 다르게 잡았습니다. 성인 여성의 부드러운 몸선과 종목별 색·장비를 전신과 전투에 함께 적용했습니다.

## 파일 규격

- `stand-mate1.webp`부터 `stand-mate16.webp`까지 720×1280 투명 전신입니다. 컷인에서 얼굴을 자를 수 있도록 머리를 상단 중앙에 배치했습니다.
- 대결용은 280×255 투명 WebP이며 오른쪽을 봅니다. `mate{n}.webp`와 `thug{n}.webp`는 대기 기본 그림입니다. 지역 두목의 기본 그림은 `thug-boss{n}.webp`입니다.
- `motion-{id}-{ready,step,windup,strike,follow,hit,down,guard,open}.webp`가 있습니다. 동료는 각자 `motion-mate{n}-skill-a.webp`와 `-skill-b.webp`를 준비와 타격 순서로 씁니다.
- 지면을 딛는 그림의 발은 같은 바닥 높이를 기준으로 맞췄습니다. 태권도 회전차기 스킬은 공중 동작입니다.
- 졸개 8종의 `step`, `follow`, `guard`, `open`은 각 캐릭터의 기본 그림을 바탕으로 만든 보조 프레임입니다.

## 연결할 ID

동료 이름과 무술 순서는 `game.js`의 `COMPANIONS`와 동일합니다. 포트레이트와 대결 그림 모두 해당 동료의 `mate1`부터 `mate16`을 사용합니다. 졸개는 `thug1`–`thug8`, 지역 두목은 `thug-boss1`–`thug-boss4`입니다.
